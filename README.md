# Climb donation site (public)

The public donation page for climbing all 14 mountains above 8,000 metres, in 10 languages:
English, नेपाली, हिन्दी, 中文, 日本語, 한국어, Español, Français, Deutsch, Italiano.

| File | What to edit |
|---|---|
| `index.html` | Nothing (the page itself) |
| `config.js` | Firebase keys, your name, email, default language, minimum amount |
| `translations.js` | All page text in every language, including your headline and story |

Full setup instructions, including GitHub Pages, are in `SETUP.md`.
